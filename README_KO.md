# 보람 RMS Lite 0.6.3 — 빠른 신청서 전환·이름 복사

공개 저장소입니다. [최신 배포](https://github.com/ahnsungkwon/boram-rms-lite/releases/latest)에서 계정·토큰 없이 설치 파일을 받습니다. [MIT License](LICENSE)로 무료·상업적 이용, 수정·재배포가 가능하며 저작권·라이선스 고지를 유지해야 합니다. [공유 안내](PUBLIC_SHARING.md)와 [외부 구성요소 고지](THIRD_PARTY_NOTICES.md)를 확인하세요.

실제 검수 결과는 해당 버전 배포본 TEST_SUMMARY.txt에 포함됩니다. 로컬 수정본 생성과 GitHub 공개 게시는 별개입니다.

## 이름만 자동 복사

신청서를 선택하면 `4홍길동.jpg`에서 `홍길동`만 클립보드에 복사합니다. 구좌수·확장자는 제외합니다. 별도 전화번호나 생년월일을 복사하지 않습니다. 이름 변경을 저장하면 새 이름으로 복사하고, 카드 등 상태만 저장할 때는 다시 덮어쓰지 않습니다. ‘이름 복사’ 버튼으로 현재 신청서의 저장된 이름을 다시 복사할 수 있습니다.

이미지 미리보기와 앞뒤 신청서를 메모리에서 재사용하며, 체크 시에는 해당 행만 갱신합니다. 이미지 표시 품질은 최대 3200px로 유지하고 원본 신청서를 압축하거나 변경하지 않습니다.

## 패널을 분리하면 이미지 영역이 넓어집니다

리네임 또는 신청서 목록의 ↗를 누르면 패널을 별도 창으로 열고, 원래 빈 열과 분할선을 접어 이미지 공간으로 합칩니다. 둘 다 분리하면 이미지 패널이 전체 작업 너비를 사용합니다. 이미지 위의 ‘리네임 복귀’·‘목록 복귀’, 분리창의 ‘복귀’ 또는 닫기를 누르면 이전 너비로 돌아옵니다.

입력 중 이름·체크·선택은 유지합니다. 분리창에서도 Space는 다음, Ctrl+Space는 이전입니다. 사진은 비율을 유지하고 전체가 보이게 맞추므로, 이미 창 높이를 채운 세로 사진은 가로 공간 증가만으로 더 커지지 않을 수 있습니다. 더 크게 읽을 때는 휠로 확대하세요.

새 PC는 BoramRMS_Lite_0.6.2_Setup.exe로 앱과 실행 환경·바로가기를 설치합니다. Python은 필요하지 않습니다. Pretendard는 선택 시 공식 배포처에서 받으며, 미선택하면 기본 글꼴로 사용합니다.

## 화면이 작을 때

상단 **화면 배율**에서 **80 / 85 / 90 / 95 / 100%**를 선택합니다. 기본 90%, 작은 화면은 80~85%, 큰 글자는 100%를 사용하세요. 다음 실행에도 선택이 유지됩니다. 버튼·글자·간격을 함께 조절하며 Windows 배율 설정이나 신청서 원본은 변경하지 않습니다.

이 배율은 신청서 이미지의 휠 확대와 별개입니다. 배율·창 크기가 바뀌면 이미지는 전체 보기로 다시 맞춥니다. 입력 중 이름과 체크·메모는 유지합니다. 리네임·목록의 여백을 줄였으며, 아래쪽 항목은 세로 스크롤로 접근합니다. 모든 항목이 항상 한 화면에 표시되는 것은 아닙니다.

## 신청서 폴더 고르기

처음 여러 폴더를 열 때: **+ 폴더 선택 → 상위 폴더 → 검색·체크 → 선택한 폴더 열기**. 처음에는 모두 미선택이며, 검색어를 바꿔도 체크한 폴더는 유지됩니다. ‘표시 항목 선택’은 현재 검색 결과만 선택합니다.

이미 열린 폴더를 바꿀 때: 오른쪽 **신청서 목록 → 작업 폴더** 드롭다운에서 고릅니다. 상단 탭과 연동되며 그 폴더에서 보던 이미지로 돌아갑니다. 현재 입력을 저장할 수 없으면 이전 폴더와 초안을 유지하고 오류 이유를 표시합니다.

검색은 선택한 경로 아래 최대 3단계, 방문 폴더 500개·후보 200개로 제한합니다. 읽기 실패나 검색 한도는 경고로 표시합니다. 신청서 폴더를 찾으면 내부 카드 폴더를 별도 작업으로 중복 분리하지 않습니다. 자료 이동·복사는 하지 않습니다.

## 읽기 쉬운 사용 안내

상단 **사용 안내**에서 **빠른 시작 / 단축키·버튼 / 폴더·화면 / 저장·주의**를 선택합니다. 화면 구성 그림, 3단계 작업 카드, 단축키 키캡, 버튼 비교로 안내합니다. 작은 창에서도 분류 버튼을 유지하고 본문만 스크롤합니다.

## 테마 바꾸기

상단 작업 탭 줄의 오른쪽 **테마 · 녹색 ▾**를 누르고 **녹색 / 블루 / 보라 / 핑크** 중 하나를 선택하세요. 현재 테마 이름과 색상칩, 메뉴의 선택 표시가 함께 바뀝니다. 재시작 없이 즉시 적용하고 다음 실행에도 유지합니다.

창 배경·상단·선택한 탭과 목록·버튼·체크 표시·입력 테두리·진행 표시·RMS 로고가 함께 바뀝니다. 열려 있는 분리창·업데이트창·사용 안내창에도 반영합니다. 신청서 이미지의 원래 색상과 오류·보완·취소 등 의미가 있는 상태색은 그대로 유지합니다. Windows 탐색기의 EXE 및 고정 바로가기 아이콘은 기본 녹색일 수 있습니다.

테마 변경은 파일명·체크·메모·검색·정렬·선택 이미지·확대 위치를 다시 저장하거나 초기화하지 않습니다. 별도 파일 `theme.json`에 선택을 저장하므로 폴더·작업 복원 설정과 섞이지 않습니다. 테마 설정만 읽지 못하면 기본 녹색으로 열리며 신청서 작업은 계속할 수 있습니다.

## 한 장씩 처리하기

폴더 열기 → 이미지 확인 → 필요한 항목 체크 → Space. 이름을 바꿀 때만 입력하면 됩니다.

**구좌수 + 이름을 비워도 다음·이전 이동이 됩니다.** 빈칸이나 공백은 기존 파일명 유지로 처리합니다. 이름을 비운다고 파일명이나 신청서가 삭제되지 않으며, 체크 상태는 이름과 별개로 저장합니다.

| 조작 | 결과 |
|---|---|
| 보완 사유 체크·해제 | 즉시 저장합니다. 복수 사유를 함께 저장합니다. |
| 카드·주말미등록·추가·입력전취소·입력후취소·미성년자 체크·해제 | 이름 저장 버튼과 무관하게 즉시 저장합니다. |
| Space | 이름을 저장하고 다음 이미지로 이동합니다. |
| Ctrl+Space | 입력한 이름이 있으면 저장하고 이전으로 이동합니다. 빈칸이면 기존 파일명으로 이동합니다. |
| 빈 이름 + Space | 기존 파일명을 그대로 유지하고 다음으로 이동합니다. |
| 저장만 / Ctrl+S | 현재 이름을 저장하고 머뭅니다. 남은 메모가 있으면 함께 저장합니다. |
| 목록 또는 좌우 이미지 화살표 클릭 | 현재 입력을 저장한 다음 해당 이미지로 이동합니다. |
| 상태 모두 해제 | 현재 이미지의 체크와 상태 메모를 비우고 즉시 저장합니다. |

체크할 때 이름을 작성 중이더라도 입력 중인 이름·커서·이미지 확대 위치는 바꾸지 않습니다. 체크 저장이 끝나기 전에 이동을 요청하면 먼저 저장이 끝나기를 기다립니다. 상태 저장으로 이미지가 다른 폴더로 이동하지 않습니다.

메모는 입력칸을 벗어나거나 이름 저장·이미지 이동 시 저장됩니다. 검색·메모 입력칸의 Space는 공백을 입력합니다. 키보드로 체크박스에 초점을 둔 경우 Space는 체크를 전환합니다. 마우스로 체크한 뒤에는 이름 입력칸으로 초점을 돌려 다음 Space로 이미지 이동을 할 수 있도록 했습니다.

여러 보완 사유와 카드·주말미등록·추가·미성년자 등을 함께 선택할 수 있습니다. 입력전취소와 입력후취소는 동시에 적용하지 않고 나중에 선택한 항목으로 바뀝니다. 입력전변경과 입력후변경도 서로 대체됩니다.

## 저장 실패와 입력 취소

일반 이동 때 `입력을 버리고 이동할까요?` 팝업은 표시하지 않습니다. 저장할 수 있으면 저장하고 이동합니다. 이름이 잘못됐거나 같은 이름이 있거나 파일이 읽기 전용이면 현재 이미지에 머무르며 **어느 파일의 무엇이 저장되지 않았는지** 하단에 표시합니다.

`상태 다시 저장`은 자동 저장이 실제로 실패했을 때만 오류 설명 바로 아래에 표시되는 버튼입니다. 정상 체크 작업에서는 누를 필요가 없습니다. 체크 아래 안내는 저장 중·즉시 저장 완료·실패를 구분합니다.

`입력 원래대로`는 이름 입력 아래에 항상 표시하는 일반 버튼입니다. 아직 저장하지 않은 이름·메모·실패한 체크 입력만 저장된 값으로 다시 읽습니다. 빈 이름으로 이동할 때 이 버튼을 누를 필요는 없습니다. **이미 자동 저장된 체크는 취소하지 않습니다.** 자동 저장된 직전 체크를 취소하려면 그 체크를 해제하거나 `마지막 변경 취소`를 사용합니다.

창을 닫거나 다른 탭·폴더로 이동할 때도 현재 입력을 먼저 저장합니다. 저장 실패를 무시하고 입력을 버리지 않습니다.

## 이전 폴더 열기 — 기존 ‘작업 복원’

지난번 앱 종료 시 열어 두었던 폴더와 선택한 이미지를 다시 엽니다. 예를 들어 세 개 행사 폴더를 열어 작업하다가 종료했다면 다시 해당 폴더를 열 수 있습니다. **삭제된 이미지를 복구하거나 파일명·체크 상태를 과거로 되돌리는 기능이 아닙니다.**

## 마지막 변경 취소 — 기존 ‘되돌리기’

현재 폴더에서 이번 앱 실행 중 마지막으로 저장한 이름·체크·메모 또는 회전 **1건**을 취소합니다. 버튼에 마우스를 올리면 대상 파일과 변경 종류가 표시됩니다. 취소할 기록이 없거나 아직 저장 중이면 비활성화됩니다.

예를 들어 카드 체크를 저장한 직후 이 버튼을 누르면 그 체크 변경을 취소합니다. 그 뒤 이름을 변경했다면 취소 대상은 마지막 이름 변경입니다. 폴더 전체를 과거로 되돌리는 기능이 아닙니다.

파일 삭제·300KB 압축·업데이트는 취소하지 못합니다. 앱을 종료하면 이 취소 이력은 초기화됩니다. 이후 외부 프로그램에서 수정한 파일은 무조건 덮어쓰지 않습니다. 상단 `사용 안내`에서 이 설명을 확인할 수 있습니다.

## 이름과 이미지 보기

이름을 먼저 쓰고 숫자를 나중에 입력해도 숫자가 앞 구좌 영역으로 들어갑니다. `홍길동12`를 붙여 넣으면 미리보기·저장에서 `12홍길동`으로 정리합니다. 기존 구좌수를 교체할 때는 앞 숫자를 선택해서 바꿉니다.

창이나 패널 크기가 바뀌면 전체 이미지가 보이도록 다시 맞춥니다. 단순 이미지·탭 전환에서는 확대·위치를 유지합니다. 휠 확대·드래그·맞춤·분리창·검색·정렬·다중 선택은 유지합니다.

입력전변경의 구좌 숫자를 실제로 넣으면 이름 저장·이동 시 파일명에 적용합니다. 숫자가 비어 있으면 이름을 바꾸지 않고 체크 상태만 저장합니다. 입력후변경은 상태 정보로 기록하며 구좌 숫자로 파일명을 자동 변경하지 않습니다.

## 원본 보호와 저장 위치

새 상태는 이미지 폴더의 `.rmslite` 안에 이미지별로 저장됩니다. 폴더를 옮길 때 `.rmslite`도 함께 복사해야 상태가 유지됩니다. 기존 `.boramrms` 로컬 상태는 새 기록이 없는 경우 읽기 호환용으로만 사용하며, 이전 저널과 백업을 삭제하거나 강제로 완료 처리하지 않습니다.

리네임은 현재 이미지에만 적용됩니다. 행사 TXT·구좌별 가공본·jpg 사본·기존 전체 RMS 상태 파일을 함께 수정하지 않습니다. 같은 폴더를 전체 RMS와 Lite에서 동시에 편집하지 마세요.

`선택 파일 휴지통 이동`은 선택한 이미지 경로만 확인 후 처리합니다. 선택하지 않은 사본·TXT·상태 파일은 삭제하지 않습니다. 휴지통을 지원하지 않는 경로에서는 영구삭제로 전환하지 않습니다.

`300KB 미만으로 줄이기`는 현재 검색·필터 결과 중 큰 파일을 300,000바이트 미만으로 같은 파일명·형식에 직접 저장합니다. **압축은 새 백업을 만들지 않고 되돌릴 수 없습니다.** 삭제·원본 압축의 실행 확인창은 유지합니다.

## 업데이트

새 정식 Release가 게시된 뒤 `업데이트 확인 → 업데이트 설치`로 받습니다. 다시 열린 창에 표시된 버전을 확인하세요. 현재 사용 중인 버전은 소스 수정만으로 교체되지 않습니다. 공개 Release를 받기 위한 개인 토큰은 필요하지 않습니다. 기존 0.6.1 앱의 비공개 인증 설명은 공개 이전 문구이며, 만료된 저장 토큰으로 401 오류가 나면 ‘저장 토큰 지우기’를 확인하세요. 개인 인증정보는 다른 사람이나 배포 ZIP에 넣지 마세요.

0.6.0은 합성 실행 시험 129개를 통과했습니다. 1024×720 논리 크기 창의 5개 배율, 스크롤 끝 항목 접근, 이름 글자 경계, 폴더 전환 및 원본 보존을 검수했습니다. NAS 장시간 작업·모든 물리 키보드/IME·모니터 배율 및 모든 장애 환경의 업데이트 복구를 보장하는 것은 아닙니다.
