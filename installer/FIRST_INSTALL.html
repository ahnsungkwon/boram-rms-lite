처음 설치: 3단계

① 설치 파일 전달·실행

BoramRMS_Lite_0.6.1_Setup.exe를 새 PC로 복사하고 더블클릭합니다. ZIP을 풀거나 명령어를 입력할 필요가 없습니다. 관리자 권한으로 실행하지 마세요.

설치 프로그램은 Windows 10/11 64비트와 .NET Framework 4.8 이상을 기준으로 제작됐습니다. Windows 11과 Windows 10 1903 이후 버전에는 이 Windows 구성요소가 포함됩니다. 구형·제한된 회사 PC는 관리자에게 호환성을 확인하세요.

② 옵션 확인 → 설치 시작

바탕화면 바로가기와 시작 메뉴를 선택합니다. Pretendard 공식 다운로드·설치는 선택 사항입니다. 기본값은 미선택이며, 선택하면 인터넷으로 공식 서체를 받아 현재 사용자에게 설치합니다. 기존 서체는 덮어쓰지 않습니다.

앱 자체는 인터넷·GitHub 로그인 없이 설치됩니다. 설치 드라이브에 최소 1.2GB 여유 공간을 확보하세요.

③ 앱 실행 → 폴더 선택

완료 화면의 앱 실행을 누릅니다. 다음부터는 바탕화면 보람 RMS Lite를 더블클릭하세요. 앱에서 + 폴더 선택으로 신청서가 있는 폴더를 엽니다.

작은 화면은 화면 배율 80~85%, 기본은 90%입니다. 테마에서 녹색·블루·보라·핑크를 선택할 수 있습니다. 리네임·목록을 분리하면 빈 공간을 신청서 이미지 영역이 사용합니다. 이미지 위의 ‘리네임 복귀’·‘목록 복귀’로 돌아옵니다.

다른 PC로 신청서 작업도 옮기려면

이미지만 골라 복사하지 말고 신청서 폴더 전체를 복사하세요. 체크와 메모가 담긴 .rmslite도 함께 있어야 상태가 유지됩니다. 과거 자료의 .boramrms가 있으면 함께 보관하세요. 기존 PC의 AppData 전체나 인증 토큰은 옮기지 않습니다. 같은 폴더를 두 PC에서 동시에 수정하지 마세요.

공개 다운로드 · 개인 토큰 불필요

최신 배포 페이지에서 로그인 없이 설치 파일을 받을 수 있습니다. 다른 사람에게 이 링크를 공유하세요. 앱은 업데이트 확인 → 업데이트 설치를 사용합니다.

공개 파일 다운로드를 위해 새 개인 토큰을 만들 필요는 없습니다. 기존 앱의 ‘비공개 저장소’ 문구는 공개 전 안내입니다. 만료된 앱 저장 토큰으로 401 오류가 나면 GitHub 인증 설정 → 저장 토큰 지우기를 확인하세요. 개인 토큰은 누구에게도 함께 배포하지 않습니다.
