# 보람 RMS Lite — 처음 설치 도구 1.0.1

패널 분리 시 이미지 영역을 확장하는 앱 **0.6.1**을 내장하도록 연결했습니다. 기존 0.6.0 배포·설치 파일은 보존합니다.

## 사용자 실행

`BoramRMS_Lite_0.6.1_Setup.exe` 더블클릭 → 바로가기·선택 서체 확인 → 설치 시작 → 앱 실행. Python은 필요하지 않습니다. 기본 위치는 `%LOCALAPPDATA%\Programs\BoramRMSLite\App`이며 앱용 실행 환경은 패키지 안에 있습니다.

기존 설치·신청서·다른 바로가기를 덮어쓰지 않습니다. 기존 사용자는 앱의 업데이트 기능을 사용하세요. 새 PC용 절차는 FIRST_INSTALL.html에 있습니다.

## 패널 분리 수정 포함

리네임/목록을 분리하면 원래 열과 분할선을 접어 중앙 이미지에 공간을 돌려줍니다. 양쪽을 분리하면 이미지 패널이 작업 영역 전체 너비를 사용합니다. 이미지 위 복귀 버튼 또는 분리창의 복귀/닫기로 이전 너비를 복원합니다. 이미지 비율을 유지하므로 전체 보기의 사진 크기는 창 높이에도 제한됩니다.

## 서체

서체 바이너리는 설치 EXE·GitHub 소스에 포함하지 않습니다. 선택하면 대상 PC에서 Pretendard 공식 v1.3.9 ZIP을 다운로드하고 해시·라이선스·OpenType 구성을 확인해 현재 사용자에게 등록합니다. 기본값은 미선택이며 맑은 고딕으로도 사용 가능합니다.

기존 설치 EXE의 공식 ZIP 47,304,526바이트 다운로드·해시·라이선스 및 4개 굵기 메모리 로딩 검수는 성공했습니다. 파일 저장·Windows 사용자 서체 등록·레지스트리 변경은 이 검수에 포함되지 않습니다. 새 1.0.1 설치 EXE도 같은 검수를 다시 통과해야 최종 파일을 생성합니다.

## 검증과 배포 증거

2026-09-19 개발 Release 빌드는 경고 0개·오류 0개이며 합성 회귀시험 137개 통과·실패 0개를 확인했습니다. K02는 세로·긴 세로·가로 이미지에 대해 실제 영역의 최대 맞춤, 종횡비, 경계와 가용 공간 증가에 따른 확대를 검사합니다. 확인 자료는 tests-data/v061/run_20260919_001310_025입니다. 배포용 앱·설치 EXE의 재검수 및 GitHub 게시 완료 여부는 아래 결과 파일로 구분합니다. 기존 0.6.0 설치본의 검수 기록을 새 수정본의 결과로 사용하지 않습니다.

새 배포는 앱 137개 이상 시험과 K01~K08, 설치 15개 시험, 설치된 앱의 동일 회귀시험, 공식 서체 다운로드·메모리 검수를 모두 통과해야 합니다. 결과는 `dist/releases/0.6.1/BUILD_RESULT.json`, `dist/setup/0.6.1/SETUP_BUILD_RESULT.json`과 `SETUP_PUBLISH_RESULT.json`으로 확인합니다.

```text
python release.py build
python installer/build_setup.py
# 결과·화면·변경 파일 검토 후 소스만 main에 커밋·push
python release.py publish
python installer/publish_setup.py
```

게시 도구는 비공개 저장소를 확인하고 새 v0.6.1 앱 Release에 설치 EXE·안내·해시 정보를 추가합니다. 이미 게시된 자산을 덮어쓰거나 태그를 바꾸지 않습니다. 실행 중 앱과 실제 고객 자료를 개발 시험에서 변경하지 않습니다.

설치 EXE는 코드서명이 없습니다. 백신·SmartScreen·조직 정책을 끄지 말고, 출처와 배포 해시를 확인하세요. Windows 제거 항목은 등록하지 않습니다.
