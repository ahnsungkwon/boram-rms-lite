## 현재 상태

소스 버전은 **0.6.2 — 상태 저장·회전의 일시 파일 잠금 처리**입니다. 일시 공유 잠금은 제한 자동 재시도하며, 외부 변경·권한 오류는 덮어쓰지 않고 입력을 보존합니다. 리네임·목록을 분리하면 빈 열·분할선 공간을 이미지 영역으로 합칩니다. 복귀 시 이전 너비를 되돌립니다. 새 버전의 실제 검증 결과는 배포본 TEST_SUMMARY.txt를 확인하세요. 미검수 소스는 배포하지 않습니다.

새 PC는 해당 버전의 Setup.exe로 처음 설치할 수 있습니다. Python은 필요하지 않고 실행 환경이 포함됩니다. 기존 사용자는 앱의 업데이트 기능을 사용합니다. 설치 EXE의 서체 옵션은 공식 다운로드이며 서체 파일이나 토큰을 내장하지 않습니다.

## 화면 배율·폴더 목록·사용 안내

상단 **화면 배율**에서 80·85·90·95·100%를 선택합니다. 기본값은 기존 RMS와 같은 90%이며 마지막 선택은 별도 `display.json`에 저장합니다. 이미지 휠 확대와 별개로 버튼·글자·간격을 함께 조절합니다. 배율을 바꾸면 이미지 전체를 새 작업 영역에 맞추고, 미저장 이름·체크·메모는 유지합니다. 분리창·안내·업데이트·폴더 선택 창에도 적용합니다.

리네임 제목·체크·메모 간격과 목록 행을 줄였습니다. 이름 입력칸 높이는 유지하여 한글 잘림을 방지합니다. 1024×720 논리 크기의 창에서 5개 배율과 마지막 항목 스크롤 접근을 검수했습니다. 모든 항목이 한 화면에 들어간다는 의미는 아니며, 작은 화면에서는 80~85%와 세로 스크롤을 함께 사용합니다.

여러 신청서 폴더가 있는 **상위 폴더**를 고르면 검색·체크 목록에서 필요한 폴더만 열 수 있습니다. 열린 폴더는 오른쪽 신청서 목록 위 **작업 폴더** 드롭다운으로 전환합니다. 폴더 전환 전에 현재 입력을 저장하며 그 폴더의 선택 이미지 위치를 복원합니다. 폴더 검색은 선택 범위 아래 최대 3단계·방문 500개·후보 200개이며 누락 가능성은 경고로 표시합니다.

**사용 안내**는 빠른 시작 / 단축키·버튼 / 폴더·화면 / 저장·주의로 나누고 화면 구성 그림·3단계 카드·키캡을 제공합니다.

## 색상 테마

상단 작업 탭 줄의 오른쪽 **테마 · 녹색 ▾** 버튼을 눌러 녹색·블루·보라·핑크를 선택합니다. 즉시 적용하며 앱을 다시 시작해도 선택이 유지됩니다. 분리창·업데이트창·사용 안내창, 상단 RMS 로고와 실행 중 창 아이콘도 함께 바뀝니다. 탐색기의 EXE 아이콘과 기존 고정 바로가기는 기본 녹색 아이콘을 사용할 수 있습니다.

색상만 바꿉니다. 입력 중 이름·체크·메모, 선택 이미지, 확대·위치, 검색·정렬·다중 선택은 초기화하지 않습니다. 신청서 이미지에 색조를 입히지 않습니다. 오류·취소·보완·카드와 구좌별 표시색은 의미를 유지합니다. 테마 설정은 작업 기록과 별도인 `%LOCALAPPDATA%\BoramRMSLite\theme.json`에 저장합니다.

## 기본 조작

**↓ 또는 Space는 다음, ↑ 또는 Ctrl+Space는 이전. 이름 입력이 비어 있으면 기존 파일명을 유지하고 이동합니다. 체크는 즉시 저장됩니다.**

구좌수와 이름을 새로 입력할 필요는 없습니다. 빈칸·공백은 이름 변경 안 함으로 처리하고 `.jpg` 같은 빈 파일명을 만들지 않습니다. 실제로 이름을 바꿀 때의 중복 파일명·잘못된 문자 검사는 유지합니다.

보완 사유와 카드·주말미등록·추가·입력전취소·입력후취소·미성년자는 체크와 해제가 바로 저장됩니다. 이름을 작성 중이어도 체크 저장은 이름이나 이미지 보기를 건드리지 않습니다. 메모는 입력칸을 벗어날 때 저장합니다.

목록·좌우 화살표·다른 탭으로 이동할 때 현재 입력을 저장합니다. 설명 없는 입력 폐기 팝업은 사용하지 않습니다. 저장 실패 시 파일명과 이유를 하단에 표시하고 현재 입력을 보존합니다. 버릴 입력은 사용자가 명시적으로 이름 입력 아래의 일반 버튼 `입력 원래대로`를 누릅니다. 빈 이름으로 이동할 때는 이 버튼을 누를 필요가 없습니다. 실제 상태 저장 오류에는 이유와 `상태 다시 저장` 버튼을 같은 위치에 표시합니다.

`이전 폴더 열기`는 지난번 폴더와 선택 이미지를 다시 엽니다. 파일 내용을 복구하지 않습니다. `마지막 변경 취소`는 현재 폴더에서 이번 실행 중 마지막으로 저장한 이름·체크·메모·회전 1건을 취소합니다. 대상은 버튼 설명에서 확인합니다. 삭제·압축·업데이트는 취소 대상이 아닙니다. 자세한 설명은 앱 상단 `사용 안내`에 있습니다.

## 독립적인 데이터 처리

상태는 이미지별 `.rmslite` 기록에 저장합니다. 이름 변경은 현재 이미지에만 적용합니다. 상태에 따라 폴더를 옮기거나 행사 TXT·가공본·jpg 사본을 수정하지 않습니다. 과거 `.boramrms` 저널과 백업은 삭제하거나 강제 완료 처리하지 않습니다.

파일명 충돌·외부 변경·읽기 전용 파일 보호를 유지합니다. 선택 이미지 휴지통 이동 및 원본 압축은 실행 전에 확인합니다. **직접 압축은 원본을 덮어쓰며 새 백업을 만들지 않으므로 되돌릴 수 없습니다.**

## 실행과 업데이트

HomePC: `C:\BoramRMS\boram-rms-lite\START_LITE.cmd`.

정식 Release가 게시되면 앱의 `업데이트 확인 → 업데이트 설치`로 받습니다. 다른 PC는 해당 버전의 ZIP 전체를 새 전용 폴더에 풀어 `BoramRMS_Lite/BoramRms.Lite.exe`를 실행합니다. EXE만 복사하지 마세요. .NET 런타임이 포함됩니다. 앱 사용에 Codex·Python·API 키가 필요하지 않습니다.

공개 Release 다운로드에는 개인 토큰이 필요하지 않습니다. 기존 0.6.1 앱에는 공개 전의 ‘비공개 저장소’ 안내가 남아 있을 수 있습니다. 토큰이 없어도 요청할 수 있으며, 만료된 저장 토큰으로 401 오류가 날 때는 `GitHub 인증 설정 → 저장 토큰 지우기`를 확인하세요. 토큰을 타인이나 배포본에 포함하지 마세요.

