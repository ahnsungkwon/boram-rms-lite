# 보람 RMS Lite

Windows x64 독립 신청서 작업 앱. 연녹색 테마, 폴더별 탭, 이미지 확인, 리네임, 로컬 상태/목록 관리, 기존 파일을 300KB 미만으로 줄이는 직접 압축을 제공합니다. **직접 압축은 실행 확인 후 원본에 덮어쓰며 별도 백업을 만들지 않습니다.**

현재 버전: **0.3.0**. 전체 RMS와 별도 프로젝트입니다. 자동입력·보람ERP·종합통계·마감·보고서 기능은 포함하지 않습니다.

## 실행

Releases에서 `BoramRMS_Lite_0.3.0_win-x64.zip` 전체를 새 폴더에 풀고 `BoramRMS_Lite/BoramRms.Lite.exe`를 실행합니다. .NET 실행 환경을 포함합니다. EXE만 따로 옮기지 마세요.

HomePC 프로젝트에서는 `START_LITE.cmd`를 실행합니다. 앱 파일과 신청서 자료는 반드시 별도 폴더에 보관하세요.

## 0.3.0 화면과 조작

흰 패널과 연녹색 강조로 화면을 정리했습니다. 이미지 좌우 클릭으로 이전/다음 이동이 가능하고, 다음 이미지에서도 확대율과 이동 위치를 유지합니다. Space는 이름을 편집했으면 저장 후 다음으로, 편집하지 않았으면 파일 변경 없이 다음으로 이동합니다. 검색·메모·체크박스의 Space는 원래 입력 동작을 유지합니다.

트레이싱, 별도 리사이즈 옵션 창, 보완자료 대상 선택과 대체 이동 조작은 제거했습니다. 리네임 아래의 압축 버튼 하나로 현재 표시 목록을 처리합니다.

## 업데이트

상단 **업데이트 확인 → 업데이트 설치**. 새 배포본이 있으면 버전이 버튼에 표시됩니다. 다운로드, SHA-256/파일 목록 검증, 이전 앱 백업, 교체, 재실행 순서로 진행합니다. 설치 전에 미저장 입력을 저장해야 합니다. 사용자 설정과 신청서 폴더는 교체하지 않습니다.

저장소는 **비공개**입니다. HomePC의 기존 GitHub CLI 로그인을 사용하거나, 업데이트 창의 인증 설정에 이 저장소의 **Contents: Read** 권한 토큰을 저장합니다. 토큰은 Windows 사용자별로 암호화되며 소스/배포본에 포함되지 않습니다. 자세한 내용은 [업데이트 안내](UPDATE_GUIDE.md)를 참고하세요.

## 개발 및 배포

.NET 8 SDK와 Python 3가 필요합니다. 앱 실행에는 Python이나 Codex가 필요하지 않습니다.

```powershell
python release.py build
# 소스 검토·커밋·main push 후 명시적으로 실행
python release.py publish
```

`build`는 별도 배포 폴더, 자체 테스트 결과, 업데이트 메타데이터와 ZIP을 생성합니다. 실패한 테스트가 있으면 패키지 생성을 중단합니다. `publish`는 깨끗한 main 커밋과 올바른 비공개 저장소를 확인한 뒤 해당 버전의 새 Release만 게시합니다. 기존 Release를 덮어쓰지 않습니다. 버전은 `BoramRms.Lite.csproj`의 `Version`에서 관리합니다.
